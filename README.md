# React + Vite  
# 📆 Agenda de Compromissos

Este é um sistema web para gerenciar os compromissos do dia. Com ele, você pode cadastrar **contatos** e registrar **compromissos** vinculados a esses contatos. É uma forma prática de manter sua agenda organizada e fácil de consultar.

---

## 🧩 Funcionalidades

- ✅ Cadastro de contatos com nome e telefone  
- ✅ Registro de compromissos com data, hora e descrição  
- ✅ Associação de um contato ao compromisso  
- ✅ Visualização da lista de compromissos do dia  

---

## 🚀 Tecnologias Utilizadas

- [React](https://reactjs.org/)  
- [Vite](https://vitejs.dev/)  
- [ESLint](https://eslint.org/)  
- JavaScript  
- HTML + CSS
